# 기능 흐름 참고 화면

두 HTML은 이전 대화에서 만든 서로 분리된 모의 화면이다. 브라우저에서 열어 일부 흐름을 확인할 수 있지만 실제 계정·서버 저장·푸시·IoT는 없다. 네트워크나 실행 환경에 따라 표시가 달라질 수 있다.

사용자는 이 화면의 그래픽이 원한 방향과 다르다고 밝혔다. **최종 그래픽·색상·캐릭터 비율의 기준으로 사용하지 않는다.** 최신 요구는 `../docs/PRD.md`와 `../docs/ART_DIRECTION.md`를 따른다.

| 파일 | 참고할 내용 | 최신 명세와 혼동하지 말 것 |
|---|---|---|
| household-invitation.html | 사람·반려동물 수 설정, 미참여자 숨김, 참여 수락 뒤 등장, 입주 사진 예시 | 실제 인증 없음. 예시의 8명·4마리 상한은 제품 정책이 아님 |
| member-navigation.html | 얼굴 아이콘으로 관찰 대상 전환, 내 상태와 다른 사람 화면의 분리, 냉장고·돌봄 예시 | 자유로운 프로필 선택은 이전 데모 동작이며 실서비스의 로그인·권한 모델이 아님 |

기존 작업에서 JavaScript 문법, 간이 DOM 상호작용, Canvas 장면 출력을 확인했다. 실제 브라우저 전체 레이아웃·실기기 성능·접근성·실제 서버 통합 검증은 완료하지 않았다. 현재 패키지 정리 작업으로 그 검증 범위를 확대했다고 주장하지 않는다.

최신 기준은 v0.5 웹플랫폼 명세다. 초기 실행 파일로 이 HTML을 복제하지 않는다. 실제 가족 초대·권한·공유 저장과 최종 아트는 새 웹게임에서 구현한다.
