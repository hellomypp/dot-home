# 도트홈 명세 변경 이력

제공 PNG·맵 통합, 대표의 공유 프리셋/가구 외형, native 캐릭터 스타일, V8 호환 필드와 서버 충돌 카탈로그, 읽기 전용 방문 풍경. 기존 v0.6 기능을 유지했다. [검증과 제한](V62_INTEGRATION.md).


## v0.5 — 2026-10-31

사용자가 웹플랫폼 기술 구성과 Codex 지침 자료 수정을 명시했다. 이 채팅에서는 기획·자료를 작성하고 실제 개발은 Codex에서 진행한다.

- 모바일 우선 PWA를 PC·태블릿·모바일 반응형 웹으로 변경.
- React·TypeScript·Vite·Phaser / Java·Spring Boot·MySQL은 웹에도 적합해 유지.
- REST+SSE 중심 안을 REST+WebSocket(STOMP)으로 변경하고 구독 인가·재연결·중복 사건·다중 탭 정책 추가.
- Capacitor·네이티브 앱·앱스토어·자동 위치 감지를 현재 범위에서 분리.
- 가족 초대·인증·미참여자 숨김·얼굴 관찰·공유 저장을 웹 MVP에 유지. 단독 플레이로 축소하는 이전 제안은 채택하지 않음.
- Codex 첫 지시문·기술 선정·완료 기준 문서 추가, AGENTS·PRD·구현·그래픽 문서 정합성 수정.
- 기존 HTML은 과거 동선 참고 자료로 보존. 최종 그래픽으로 승인된 것이 아님.
- 이번 수정에서 웹게임 구현·사이트 배포·새 이미지 제작은 수행하지 않음.
