# 도트홈 v0.9 작업 단위

기준 소스 `4df3a6d`. 제품 정책은 [기획서 v0.9와 다중 홈 보완](https://app.notion.com/p/40a26d20896681b8b9f1ed3031ebd172), API·검증 목표는 [개발 명세 v0.9](https://app.notion.com/p/40a26d2089668150b006d5feb6334619)를 따른다. 최근 직접 요청으로 적용한 프리셋·모바일 화면·창밖 날씨는 현행 코드 기준으로 유지한다.

| 순서 | 단위 | 현행과 남은 검증 |
| --- | --- | --- |
| 1 | 다중 홈 선택과 초대 수명 (DH01 / A01) | 여러 집 가입과 일회성 초대 유지. 마지막 집 복원, 선택 화면, 전환 시 장면·소켓 격리, 신규 초대 7일과 기존 만료 보존을 구현한다. |
| 2 | 쪽지 입력과 보존 (DH07·DH23 / A05) | 냉장고 쪽지와 식료품 유지. 신규 300 코드 포인트 제한, 첨부 수 한도와 기존 긴 본문 보존을 검증한다. |
| 3 | 공유 상태의 독립 만료 (DH03–04·DH10 / A02·A03) | 현재 단일 TTL과 수동 장소를 호환하며 부분 수정·개별 만료·미공유와 오래된 상태를 구분한다. |
| 4 | 생활 요청과 배려 (DH05–06 / A04) | 기존 생활 기록을 보존하고 요청·약속·반응을 분리한다. 동시 담당, 기한과 완료 취소를 검증한다. |
| 5 | 일정과 대리 프로필 (DH08–09·DH16 / A04·A06·A07) | 일정 범위·작성 권한·RSVP를 추가한다. 아기·반려동물 관리와 반복 돌봄은 개별 데이터 이관 및 복구 검증을 둔다. |
| 6 | 탈퇴·퇴실·소유권 (DH17 / A12) | 다중 홈을 기반으로 즉시 권한 회수, 종료 전 초대 차단, 새 가입 및 이전 기록 익명화부터 구현한다. 공동 기록 내보내기와 집 삭제 유예·정리를 격리 DB에서 검증했다. 이전 집의 내 쪽지·일정과 삭제 로그 재적용을 구현했다. 부탁·공지와 계정 삭제는 후속 단위다. 삭제 로그 재적용 명령은 H2 복사본에서 검증했다. |
| 7 | 공간 편집·외형 (DH02·DH12–13 / A02·A09) | 프리셋, 냉장고 외형, 가구 8종의 격자 배치, 벽·바닥 마감을 같은 편집 세션에 연결했다. 비공개 초안, 가족의 범위별 승인·회수, 저장 재시도와 서버 동선 검증을 확인했다. |
| 8 | 날씨·위치·알림 (DH11·DH14–15 / A08·A10·A11) | 창밖 날씨의 30분 캐시와 마지막 관측값 2시간 이내 대체를 검증했다. 편집 권한과 가족 부탁·공지에 개인 알림함 및 집별·종류별 수신 설정을 연결했다. 접속 중 위치 공유와 기기 교체, 자동·수동 귀가 이력과 개인별 귀가 알림을 구현했다. 웹 푸시 기기 등록·조용한 시간·선택형 잠금 화면과 실제 Chrome/FCM 수신을 확인했다. iPhone·Android 실제 단말 수신은 남아 있다. |
| 9 | 비공개·공개 베타 인수 (DH22·DH24 / A15–A16) | 로컬 MySQL 8.4.7 경합·격리·집들이 회귀와 빈 검증 DB 복원·기동을 확인했다. 실제 iPhone/Android 두 계정 검증 및 공개 도메인·Google 설정·푸시 키는 운영 입력이 필요하다. |
| 10 | 후속 출시 게이트 (DH18–21 / A10·A13·A14) | 결제와 보상은 권한·원장 검증 후 별도 활성화. 사진은 기본 OFF. 백그라운드 귀가는 네이티브 플랫폼 및 운영 검증 필요. |

이 문서는 작업 단위와 순서를 기록한다. 실제 구현·검증 상태는 각 작업의 코드, 테스트 및 [검증 기록](VERIFICATION.md)에서 확인한다.
