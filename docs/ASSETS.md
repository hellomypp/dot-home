# M0 아트 시안과 엔진 규격

## 현재 집 자산: v6.2

아래는 이전 M0 시안 이력이다. 현재 집·초상화·꾸미기는 apps/web/public/art/v62의 제공 PNG를 사용한다. source-manifest.json은 원본 220개 기록, manifest.json은 포함된 runtime subset의 해시다. assets/space-catalog.json은 서버와 클라이언트가 같이 읽는다. AI 보조 원본 제작 및 네이티브 픽셀 수출 출처, 임시 고양이·코드 자석·미적 승인 미완료는 [V62_INTEGRATION.md](V62_INTEGRATION.md)에 기록했다. 직장·학교·밖은 기존 art.ts를 유지한다.


2026-11-01 첫 구현. 최종 스타일 승인이 아닌 비교 가능한 개발 시안이다.

- A: 따뜻한 목재 바닥, 세이지 벽지·소파, 크림색 생활 소품. 쯔꾸루의 위에서 내려다보는 실내 단면을 기준으로 창문, 책장, 식탁, 주방, 침대, 화분을 분리했다.
- B: 같은 배치와 캐릭터에 차분한 저녁 색감을 적용. ‘보기 설정’에서 비교한다. 실제 시간·날씨 연동이 아니다.
- `/studio`의 하늘·서윤·모카는 아트 테스트 fixture다. 실제 집의 구성원과 데이터는 API에서만 받아 생성한다.
- 직장·학교·밖은 공통 자산을 활용한 기본 공간이다. 집 스타일 검토 전에는 공간별 아트를 대량 제작하지 않았다.

## 자산과 출처

`apps/web/src/game/art.ts`가 Canvas에 직접 그린 원본 픽셀 텍스처를 Phaser에 등록한다. 기존 참고 HTML의 그림이나 타 게임의 자산을 추출하지 않았다. 외부 이미지·이미지 생성 서비스 사용 없음. 실제 출력 단위와 원본 출처는 `assets/manifest.json`에도 기록했다. 별도 PNG의 수동 편집 대신 원본 함수를 수정하면 동일하게 재생성된다.

일반 UI 아이콘은 lucide-react(ISC), 글꼴은 Google Fonts의 Noto Sans KR·DM Sans(OFL)이며 네트워크가 없으면 시스템 sans-serif로 대체된다. 엔진은 Phaser(MIT), UI는 React(MIT). 배포 전 글꼴 자체 호스팅 및 의존성 라이선스 고지 파일을 확정해야 한다. 코드·원본 아트의 최종 배포 라이선스는 프로젝트 소유자가 결정한다.

| 장면 | 640×448 논리 픽셀; 바닥 영역 x44..596, y130..406 |
| 타일·이동 | 8px 길 찾기 격자; 바닥 목재 줄 18px, 재사용 가구 텍스처 |

| 확대 | 픽셀 보간 해제. 작은 폭에서 카메라가 관찰 대상을 따라가며 과도한 축소 방지 |
| 입력 | 마우스/터치 목적지, 방향키/WASD, 입력 필드·열린 dialog에서는 이동키 무시 |
| 생명주기 | React unmount 시 엔진·ResizeObserver·키보드·visibility 리스너 정리 |

## 확인과 남은 아트 작업

Codex 내장 Chromium 화면에서 데스크톱 및 390×844 크기를 확인하고, 모바일 말풍선의 카메라 경계와 초대 관리 접근을 보완했다. 가구 통과 방지·우회 경로는 단위 테스트로 확인했다. 실제 휴대폰 터치, Safari, 여러 DPR의 픽셀 선명도, 다수 구성원 말풍선 겹침, 앉기 전용 스프라이트와 세밀한 가구 상호작용은 추가 검증·제작 대상이다. 현재 자율 행동은 걷기·대기 연출이며 실제 돌봄·재고·가전 상태를 변경하지 않는다.

## v0.6

냉장고 포스트잇은 game/index.ts에서 직접 그리는 16px 원본 사각 픽셀 표식(44px 히트 영역)이다. 방문 화면은 기존 art.ts의 makeHouse/makeFurniture를 재사용하고 가족 아바타를 렌더링하지 않는다. 신규 외부 이미지·폰트·스프라이트 라이선스는 추가하지 않았다.
