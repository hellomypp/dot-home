# 도트홈 — 웹 MVP 완료 기준 v0.5

아래는 앞으로 수행할 검증 목록이다. 현재 통과한 테스트가 아니다. 실제 실행 환경·결과는 개발 시 별도로 기록한다.

## M0: 대표 장면

- [ ] URL에서 React UI와 Phaser 장면이 실행된다.
- [ ] 쯔꾸루풍 시안·집 장면·타일/스프라이트 규격이 있다.
- [ ] 이동·가림·가구 접근·말풍선이 동작하며 가구를 통과하지 않는다.
- [ ] PC 입력·모바일 터치·크기 변경·입력 폼 포커스를 검증한다.
- [ ] 정지 그림이나 임시 데이터 시제품을 완성된 서비스로 표현하지 않는다.

## M1: 실제 참여·저장

- [ ] 대표 1명·반려동물 0마리로 시작한다.
- [ ] 계획 인원만 늘려도 미가입자의 캐릭터와 얼굴은 나타나지 않는다.
- [ ] 인증과 수락 완료 뒤에만 입주한다.
- [ ] 링크 열람·취소·만료·반복/동시 수락을 검증한다.
- [ ] 가입·프로필·반려동물이 브라우저 새로고침·서버 재시작 후 복구된다.
- [ ] 다른 가구 ID의 조회·수정은 서버에서 거부한다.
- [ ] 계획 인원 감소로 기존 가입자가 자동 삭제되지 않는다.

## M2: 공동 공간

- [ ] 두 계정·두 독립 브라우저 세션이 같은 가구를 확인한다.
- [ ] A가 B 얼굴을 눌러도 A의 계정·권한이 유지된다.
- [ ] 집·직장·학교·밖의 기본 장면과 관찰 전환이 있다.
- [ ] 관찰 공간과 실제 공유 장소 변경을 구분한다.
- [ ] 자율 행동·직접 입력 우선·유휴 복귀·반려동물 행동이 동작한다.
- [ ] SEND·SUBSCRIBE 모두 가구 접근 권한을 확인한다.
- [ ] 타인 ID 위조·topic 직접 발행·불가능한 이동 의도를 거부한다.
- [ ] 소켓 끊김·재연결·중복 사건·스냅샷 조회 중 이벤트를 처리한다.
- [ ] 다중 탭 제어권·로그아웃·세션 만료·권한 회수를 검증한다.
- [ ] 오프라인 가입자를 미가입 상태로 되돌리지 않는다.

## M3: 생활 정보·웹 출시

- [ ] 기분·음식·생각이 다른 기기에 반영되고 만료·해제할 수 있다.
- [ ] 식료품 조회·변경·사용 기록이 가구 DB에 저장된다.
- [ ] 동시 재고 수정의 손실·음수 재고를 방지하고 충돌을 처리한다.
- [ ] 수동 퇴근·귀가·택배 사건이 웹에 표시되고 이력에 남는다.
- [ ] 재전송·새로고침으로 알림이 중복 생성되지 않는다.
- [ ] 자율 연출로 실제 재고·돌봄·가전 상태가 변경되지 않는다.
- [ ] URL 직접 접근·새로고침·뒤로 가기·오프라인·오류 화면을 확인한다.
- [ ] HTTPS·쿠키·CSRF·Origin·WebSocket 프록시를 검증한다.
- [ ] 실제 OAuth 설정을 검증하고 비밀값을 코드에 포함하지 않는다.
- [ ] 지원 브라우저·실기기에서 글자·터치·캔버스·재접속을 확인하고 버전을 기록한다.
- [ ] 로딩·프레임·메모리·숨김 탭을 측정하고 관찰된 문제를 수정한다.
- [ ] DB 마이그레이션·백업·복원·기본 오류 기록 방법이 있다.

## 검사 구성

상태 전이·입력 검증에는 단위 테스트, 초대·인가·재고 충돌에는 MySQL 통합 테스트, 대표 생성→초대→참여→얼굴 관찰→공유 변경에는 브라우저 E2E를 적용한다. 실행 불가 항목은 미검증과 사유를 기록한다. 대상 기기 확정 전 임의의 성능 수치를 통과 기준으로 확정하지 않는다.
